Import full inventory (including unequipped artifacts)

No game API exposes unequipped artifacts, so they have to be scanned from the game and exported as a GOOD file (Genshin Open Object Description). Any of these produce one:

  • Genshin Optimizer: scan artifact screenshots in the browser (works on any OS), then use Database → Export.
  • Irminsul (Windows PC): reads inventory data while the game runs.
  • Inventory Kamera (Windows PC): scans the in-game inventory automatically. Not updated since 2024, so it may not support newer sets.

The file stays on this computer (.data/good.json) and is never committed.

Substats

Equipped artifacts come from HoYoLAB. The full inventory comes from your imported GOOD file. Crit Value = 2 × CRIT Rate + CRIT DMG from substats. Fit = substat rolls in the wearer's recommended stats, compared with a strong piece (see Build check). Perfect = the right main stat plus every desired substat the piece can have, once 4 desired substats are chosen. Roll counts for imported artifacts are estimated from their values.
