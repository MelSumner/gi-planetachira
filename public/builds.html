Build check

Compares each character's equipped artifacts with the stats HoYoLAB recommends for them, so you can see who needs better artifacts. HoYoLAB often lists fewer than 4 substats, so each character has a list of desired substats. Choose them with Edit desired substats. Your choices are saved on this computer and used everywhere in the app. Main stats still come from HoYoLAB.

How grades work
  • Main stats: Sands, Goblet and Circlet should have a recommended main stat. CRIT Rate and CRIT DMG circlets count as interchangeable.
  • Useful rolls: each substat roll that went into a recommended stat counts once (a substat rolled 3 times counts 3). A strong +20 five-star piece has about 4 useful rolls when 1 stat is recommended, 6 for 2, 7 for 3, and 8 for 4 or more. Four-star pieces count 80% per roll.
  • Score: average of each piece's useful rolls compared with that target. An empty slot counts as 0.
  • Grade: Great is 60% or higher, Good 45%, Needs work 30%, and Poor is below that. A missing piece or wrong main stat caps the grade at Needs work.
  • Perfect: the right main stat plus every desired substat the piece can have. This needs 4 desired substats, so set them with Edit desired substats. A substat can't match the main stat, so an ATK% Sands only needs the other desired substats.
  • Not built: characters with no artifacts equipped aren't graded and sort last.

This is a quick check of stats only. It doesn't consider set bonuses, weapons or team needs.
